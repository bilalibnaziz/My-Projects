 macOS Installation

  1. All-in-One Disk Image (.dmg):
    Open Mac/SkillSuite-v1.0-All-In-One.dmg and drag all 4 applications to the Applications shortcut.
  2. One-Click Script:
    Double-click Mac/Install-All-Mac.command in Finder to automatically install and clear quarantine flags.
  3. Standalone Apps:
    Pre-built applications are also available directly in Mac/Applications/.

⊞ Windows Installation

  1. Master One-Click Setup:
    Double-click Windows/Setup-All-Windows.bat and press Y to install the full suite with Desktop and Start Menu shortcuts.
  2. PowerShell Automated Installer:
    Run .\Windows\Install-SkillSuite.ps1 in PowerShell.
  3. Zero-Install Portable Running:
    Double-click any .bat file inside each app folder to launch immediately in frameless desktop mode.
